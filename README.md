# UML CCDC 2027 Repository

## Overview

This repository contains current tools, scripts, and documentation that plan on being used during the NECCDC competition by the UML team. They will provide support in completing injects, performing remediation, configuration management, and more.

## Structure

At the top level will be either sub domains within the competition or broader sections such as the Documentation directory. Within the sub domains they contain the automation, tooling, and respective documentation (more on docs below). This includes things like ansible playbooks, bash scripts, powershell scripts, and common commands. The Documentation directory contains inject templates, incident report templates, inventory sheets, and mock network diagrams.

## Documentation

The goal of this repository is to keep it streamlined therefore there is a limit on excess documentation. However if there is documentation that is deemed needed when in the competition environment it can be included. Think of docs such as configuration process, the common failures of a certain service, etc. Any documentation that is more focused on the "what" aspect of a broader concept or service rather than specifics is still helpful but should be stored in a separate repository.
